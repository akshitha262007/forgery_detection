# 🛡️ AI-Powered Medical Document Forgery Detector

An intelligent forensic analysis system developed using Python, Streamlit, OpenCV, and OCR techniques to detect possible tampering in medical documents.

---

## 🚀 Features

- Metadata Analysis
- Error Level Analysis (ELA)
- Dynamic Tampering Detection
- OCR Text Extraction
- Signature Verification
- AI Risk Classification
- Forensic Report Generation
- Analytics Dashboard
- PDF/Image Support

---

## 🧠 Technologies Used

- Python
- Streamlit
- OpenCV
- PIL
- NumPy
- Pandas
- Pytesseract OCR
- SQLite

---

## 📌 Project Overview

This project helps identify suspicious modifications in medical documents using computer vision and AI-based forensic analysis techniques.

The system analyzes:
- edited text
- erased content
- forged signatures
- compression inconsistencies
- suspicious document regions
